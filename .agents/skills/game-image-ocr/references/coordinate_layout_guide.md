# 游戏卡牌与战法弹窗空间坐标锚定指南 (Coordinate Layout Guide)

在处理《率土之滨》等 SLG / 卡牌策略游戏的高清截屏（尤其是横屏 4K/2K 截图）时，**单纯依靠正则表达式匹配全文极易产生错位**（例如速度成长与攻城成长颠倒、战法发动率与目标混杂）。本方案基于 Apple Vision 框架的归一化空间包围盒（Bounding Box），通过空间几何锚定实现 100% 准确提取。

---

## 1. 坐标系规范 (Apple Vision Coordinate System)

Apple Vision 的 `VNRecognizedTextObservation.boundingBox` 使用归一化坐标系：
- 原点 `(0.0, 0.0)` 位于图像的 **左下角 (Bottom-Left)**。
- 坐标范围均为 `0.0 ~ 1.0`。
- `x`：从左至右（0.0 为最左侧，1.0 为最右侧）。
- `y`：从下至上（0.0 为最底部，1.0 为最顶部）。
- `w` 与 `h`：检测框的归一化宽度与高度。

```text
(0.0, 1.0) --------------------- (1.0, 1.0)
|                                         |
|                 屏幕区域                 |
|                                         |
(0.0, 0.0) --------------------- (1.0, 0.0)
```

## 2. 武将卡牌详情面板空间结构 (Card Screen)

武将详情界面右半部分为属性与基础信息区：

```text
+-----------------------------------------------------------+
|                          [武将立绘区]                      |
|                                                           |
|             详情面板区 (x: 0.60 ~ 0.98, y: 0.35 ~ 0.78)   |
|             +-------------------------------------------+ |
|             | 攻击距离: [X]      Cost: [X.X] 兵种: [弓步骑]| | (y ~ 0.70)
|             +-------------------------------------------+ |
|             | 左列 (x < 0.80)       右列 (x >= 0.80)     | |
|             | -----------------     -----------------   | |
| (y ~ 0.495) | 攻击 XX (+X.XX)       攻城 XX (+X.XX)     | | 行 1
| (y ~ 0.445) | 防御 XX (+X.XX)       速度 XX (+X.XX)     | | 行 2
| (y ~ 0.395) | 谋略 XX (+X.XX)       [留空/其它]          | | 行 3
|             +-------------------------------------------+ |
+-----------------------------------------------------------+
```

### 宽框（Wide Box）合并问题与解决方案
- **现象**：当卡牌两列属性字体排版紧凑时，Apple Vision 会将整行识别为一个宽文本框（`w > 0.22`，例如 `攻击97 (+1.54) 攻城37 (+1.73)`）。
- **判定与拆解规则**：
  1. 若检测框位于行 1（`y > 0.46`）且 `w > 0.22`：使用关键字 `[政攻]城` 将该行切分为左半部（攻击）和右半部（攻城）。
  2. 若检测框位于行 2（`y > 0.41`）且 `w > 0.22`：使用关键字 `速度` 将该行切分为左半部（防御）和右半部（速度）。

## 3. 自带主战法详情弹窗空间结构 (Skill Popup Screen)

点击战法后弹出的居中详情弹窗：

```text
+-----------------------------------------------------------------+
|                        [居中详情弹窗]                           |
|  +-----------------------------------------------------------+  |
|  | [战法名] Lv.1 » Lv.10                     攻略 [X关闭]    |  | (y: 0.66 ~ 0.73)
|  +-----------------------------------------------------------+  |
|  | [左列标签与值: x: 0.35 ~ 0.52]  [右列标签与值: x: 0.53 ~ 0.90] |  |
|  | 战法品质: S/A/B 级              兵种类型: 弓/步/骑        |  | (y ~ 0.633)
|  | 战法类型: 主动/指挥/被动/追击    发动率: 35%/100%生效      |  | (y ~ 0.599)
|  | 有效距离: 1~6 / --              目标类型: 敌军群体/我军全体 |  | (y ~ 0.562)
|  +-----------------------------------------------------------+  |
|  | 战法描述 [简/详]                                          |  | (y ~ 0.508)
|  | --------------------------------------------------------- |  |
|  | 逐字正文区 (y: 0.28 ~ 0.50, x: 0.35 ~ 0.90)               |  |
|  | （按 Y 坐标从大到小严格自上而下排序拼接）                 |  |
|  +-----------------------------------------------------------+  |
|  |                     [底部操作按钮: 强化/拆解]             |  | (y < 0.28)
+-----------------------------------------------------------------+
```

### 战法字段提取关键点
1. **战法名称**：
   - 首选：顶部大标题正则匹配 `([^\s:：、]+?)\s*L[vV]\.1`。
   - 备选：左侧图标正下方的独立文字框（`x ~ 0.12, y ~ 0.52`）。
2. **战法描述正文区**：
   - 范围限定在 `0.28 <= y <= 0.50`，过滤掉标签词（`战法描述`、`简详`、`简`、`详`）。
   - 必须过滤掉底部按键（如 `51/强化`、`强化`、`攻略`、`拆解战法`）。
   - 按 `y` 坐标从大到小（从顶部行到底部行）排序拼接，确保语句连贯、数字与符号不乱序。
