# OCR 领域字符修正词典与边界异常处理 (Error Correction & Edge Cases)

《率土之滨》游戏字体采用自定义书法风格艺术字，配合特殊排版，在标准 OCR 识别时会产生特定高频形似错别字。本词典归纳了生产级测试中遇到的全部边界案例与修正规则。

---

## 1. 常见艺术字体形近字替换表

| 识别错误 (OCR Output) | 正确文本 (Correct Text) | 出现场景与原因 |
| :--- | :--- | :--- |
| `政击` | `攻击` | “攻”字草书偏旁与“政”极其相似 |
| `课略` / `湈略` | `谋略` | “谋”字草书言字旁粘连 |
| `王动` / `王` | `主动` | 战法类型标签中，“主”顶部的点与边框粘连被误认为“王” |
| `以逸诗劳` | `以逸待劳` | 张郃自带战法标题，“待”被识别为“诗” |
| `怀徳畏威` | `怀德畏威` | 司马昭自带战法，“德”字异体字归一 |
| `白伤害` / `造成白伤害` | `的伤害` / `造成的伤害` | “的”字左侧“白”被独立识别 |
| `造成昀伤害` | `造成的伤害` | “的”与“日”部首粘连 |
| `饮复` / `恢氨率` | `恢复` / `恢复率` | “恢”与“复”艺术字部首拆解错误 |
| `使车` | `使自身` | “自身”紧凑排版被误认为“车” |

## 2. 数值与特殊符号规范化

| 识别错误 | 正确格式 | 说明 |
| :--- | :--- | :--- |
| `»>` / `》` / `>` | `»` | 战法数值成长递增符号，统一规范为 `»` |
| `ll` / `11` (仅限有效距离字段) | `--` | 被动战法或追击战法无有效距离限制时显示的横线 `--`（注意：切勿在全局字符串替换，以免破坏 111/114 等数值） |
| `+O.71` / `+o.71` | `+0.71` | 英文字母 O / o 误认为数字 0 |
| `41.26` (属性括号内) | `+1.26` | 加号 `+` 被误认为数字 `4` |
| `（#145）` | `（+1.45）` | 加号与小数点被识别为 `#` |
| `0:82` | `0.82` | 冒号被误识别为小数点 |

## 3. UI 遮挡与低对比度边界处理

### 1) 底部按钮遮挡文字（大乔案例）
- **现象**：大乔主战法【巧音唤蝶】弹窗底部正文极长，末尾一句 `，受谋略属性影响），持续1回合` 被底部的 `51/强化` 按钮部分遮挡。
- **规则**：检测到战法名属于“大乔”且结尾缺失 `持续1回合` 时，主动补齐被遮盖的法定并列句尾。

### 2) 低对比度单数字有效距离兜底
- **现象**：部分主战法（如诸葛锦囊、辕门射戟、威震河朔）在弹出弹窗时，有效距离右侧的单一数字“5”或“4”字形细小且背景反差弱，OCR 偶发漏检。
- **规则**：维护高频自带核心战法的有效距离兜底字典，若 OCR 提取结果为 `-`，自动使用字典兜底：
  - `匠心不竭`: 4
  - `乱政`: 6
  - `辕门射戟`: 5
  - `威震河朔`: 5
  - `遗志`: 2
  - `黄天余音`: 3
  - `驱虎吞狼`: 5
  - `诸葛锦囊`: 5
  - `竭忠尽智`: 3
  - `全主诿异`: 4
  - `抚民励德`: 3
  - `怀德畏威`: 5
  - `计谕废立`: 4
  - `火兽冲锋`: `--`
  - `以逸待劳`: 3
