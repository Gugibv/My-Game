### 1. 开荒期（7本 7.0 Cost）
* **大营：大乔 (2.0C)** —— 【兵无常势】（或前期带河内世泽暂用）
* **中军：黄月英 (2.5C)** —— 【磐阵善守】 / 【战必断金】
* **前锋：乐进 (2.5C)** —— **【百战无怯】**（暂时从主力典韦借调）
* **优势**：7本直接合体出山，三核输出绝不打平，受野怪暴走影响小，**大乔吃满所有升级经验，满级（35~40级）完成开荒出山**。

### 2. 转型期（8本 8.0 Cost）
* **第四队（知己大乔吴步）**：大乔（2.0C）直接与练兵所练至 20 级的 **3红陆抗（3.0C）**、**2红周泰（3.0C）** 合体，**总 Cost 恰好 8.0C，无需升级帅令坛**，直接成型开战！
* **第三队（水镜甘典）**：将乐进的【百战无怯】洗下，正式交还给 **1红典韦**，第三队主力同时满配出战。

### 战法与宝物 0 冲突校验确认
1. **减伤与指挥体系分流**：
   * 神兵天降 + 反计之策 ➔ **第二队（魏智）**
   * 攻其不备 + 长兵方阵 ➔ **第一队（菜刀）**
   * 避其锋芒 + 三军之众 ➔ **第三队（甘典）**
   * 知己知彼 + 桃园结义 ➔ **第四队（吴步）**
   * 无心恋战 + 始计浑水 ➔ **第五队（流氓）**
2. **核心防御战法分流**：
   * 单骑救主 ➔ 第二队（曹操）
   * 垒石迎击 + 百战无怯 ➔ 第三队（典韦）
   * 健卒不殆 + 步步为营 ➔ 第四队（周泰）
   * 兵无常势 ➔ 第四队（大乔）
   * 重整旗鼓 ➔ 第五队（张机）
3. **极品宝物对号入座**：
   * 冥山勾月（曹纯）、屈卢（张辽）、元戎（文鸯）
   * 涂氏匕首（荀彧）、鸣鸿（司马懿）、大将（曹操）
   * 乌翦（甘宁）、仁风（司马徽）、大橹（典韦）
   * 游飘（大乔）、承影（陆抗）、博浪坚忍（周泰）
   * 彤素（赵云）、博浪仁心（张机）、别鸣（孙权）
